# Security policy

## Supported versions

This project is a **research / portfolio simulation**. There is no production support SLA. Fixes land on `main` as best effort.

## What to report

Please report vulnerabilities that could affect users running the local API, desktop launcher, or dependency supply chain (e.g. unintended network exposure, path traversal in scenario loading, dependency CVEs).

Do **not** treat simulated jammer/kinetic models as a security boundary for real systems—they are not connected to physical effectors in this repository.

## How to report

Open a GitHub Security Advisory on the repository if available, or email the maintainer address listed on the GitHub profile owning the repo. Include:

- Affected commit / tag
- Reproduction steps
- Impact assessment

Please allow reasonable time before public disclosure.
